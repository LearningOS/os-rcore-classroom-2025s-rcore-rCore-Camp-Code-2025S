# SV39 页表项（Page Table Entry, 简称 PTE）组成

SV39 是 RISC-V 架构下常用的 39 位虚拟地址空间的页表格式。  
在 SV39 中，每个页表项（PTE）是 64 位的，具体组成如下：

| 位段       | 名称       | 描述                         |
|:-----------|:-----------|:------------------------------|
| 0          | V (Valid)   | 有效位，1 表示该 PTE 有效。    |
| 1          | R (Read)    | 读权限，1 允许读。            |
| 2          | W (Write)   | 写权限，1 允许写。            |
| 3          | X (Execute) | 执行权限，1 允许执行。        |
| 4          | U (User)    | 用户模式访问权限。            |
| 5          | G (Global)  | 全局映射，跨地址空间共享。    |
| 6          | A (Accessed)| 被访问过标志，硬件设置。      |
| 7          | D (Dirty)   | 被写过标志，硬件设置。        |
| 8-9        | RSW         | 软件保留位，自定义使用。      |
| 10-53      | PPN (Physical Page Number) | 指向物理页框的物理页号。 |
| 54-63      | Reserved    | 保留，必须是 0。              |

---

# 标志位作用详解

| 标志位 | 作用 |
|:------|:-----|
| **V (Valid)** | 如果是 0，这个 PTE 是无效的（不管其他位如何）；如果是 1，则进一步看 R/W/X。 |
| **R (Read)** | 是否允许 CPU 通过这个映射读取内存。 |
| **W (Write)** | 是否允许 CPU 写入内存。 |
| **X (Execute)** | 是否允许 CPU 执行这块内存（通常是程序代码段）。 |
| **U (User)** | 设为 1，表示用户模式程序可以访问；否则只有特权模式能访问。 |
| **G (Global)** | 标记为全局映射，所有地址空间都可以共享，不需要在上下文切换时刷新 TLB。 |
| **A (Accessed)** | 硬件在访问到这个页时置位；如果 0，说明从未被访问（可能被页回收策略使用）。 |
| **D (Dirty)** | 硬件在写入到这个页时置位；如果 0，说明页面内容是只读或未被修改（用于写回缓存策略）。 |
| **RSW (Reserved for Software)** | 软件自定义字段，比如操作系统可以用来记录额外的信息，比如权限标记或状态。 |

**1. 哪些异常可能由缺页导致？**  
- Instruction Page Fault  
- Load Page Fault  
- Store/AMO Page Fault  

---

**2. 缺页时重要寄存器：**  
- `sepc`：异常指令地址  
- `stval`：访问出错的虚拟地址  
- `scause`：异常类型  

---

**3. Lazy策略的好处：**  
- 节省内存和CPU时间  
- 加快程序启动速度  
- 提高系统资源利用率  

---

**4. 处理10G连续内存时，页表占用大致多少？**  
- 大约几十MB内存（数量级：MB级别）  

---

**5. 如何实现Lazy，缺页时处理？**  
- 初始不分配物理页，只记录映射信息  
- 缺页异常时分配物理页，更新页表，重试指令  

---

**6. Swap时页表项变化？**  
- `V=0`，失效  
- 可用保留位或额外数据记录磁盘位置

---

**1. 单页表情况下，如何更换页表？**  
- 修改 `satp` 寄存器，切换到新的页表根地址；然后执行 `sfence.vma` 刷新 TLB。

---

**2. 单页表情况下，如何控制用户态无法访问内核页面？**  
- 将内核页表项的 `U` 位（User位）设置为0，用户态访问时触发异常。

---

**3. 单页表的优势？**  
- 切换内核态时不需要切页表，减少开销；上下文切换更快；实现简单。

---

**4. 双页表实现下，何时需要更换页表？**  
- 用户态切到内核态（陷入内核）时切换到内核页表，返回用户态时切回用户页表。

**5. 写单页表操作系统时，何时更换页表？**  
- 在不同进程切换（context switch）时更换页表。
