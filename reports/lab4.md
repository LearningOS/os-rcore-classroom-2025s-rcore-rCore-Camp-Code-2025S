# 总结

1. 本节主要实现了以下几个功能：
   - 为文件添加硬链接，当创建文件或打开文件时，文件的硬链接设置为1，当Link文件时，硬链接加1
   - 为文件实现移除硬链接功能，执行Unlink时，硬链接减一，然后判断如果文件的硬链接数为一，则回收
   - 为文件实现返回Stat接口功能

# 问答题

1. root inode的作用：Easy File System提供的获取根目录的Inode，用来维护加载到内存中的文件

2. 使用 pipe 的实际应用示例：统计日志文件中包含关键字的行数

3. 使用 `cat` 和 `wc` 统计文件行数的优化方法

   ```
   wc -l file.txt
   ```

4. 基于消息队列或中间件的通信机制

   - **消息队列**：
     - 提供异步通信能力，支持多对多通信，数据以消息为单位存储和传递。
     - 使用 `POSIX` 消息队列或第三方中间件（如 RabbitMQ、ZeroMQ）
   - **共享内存 + 信号量**：
     - 通过共享内存区域实现高速数据交换，结合信号量保证同步。
     - 使用 `shmget` 创建共享内存，`semaphore` 控制访问权限。
